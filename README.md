# 🏦 Loan Approval Analysis

## 📌 Project Overview

This project focuses on analyzing financial information to understand the factors associated with loan approval.

The project uses a loan approval dataset containing applicant financial and demographic information.

The analysis is performed using Python and basic data analysis techniques.

The main goal is to inspect, clean, visualize, and understand the dataset.

This project is designed as a beginner-friendly Data Analysis and Machine Learning exercise.

---

## 📂 Dataset

**Dataset Name:** `10_loan_approval.csv`

The dataset contains information about loan applicants and their approval status.

### Dataset Columns

* `age` – Age of the applicant
* `income_lakh` – Applicant income in lakhs
* `credit_score` – Applicant's credit score
* `loan_amount_lakh` – Requested loan amount in lakhs
* `existing_loans` – Number of existing loans
* `approved` – Loan approval status

---

## 🎯 Problem Statement

Analyze financial information to understand the factors associated with loan approval.

The project aims to identify patterns in applicant information that may be related to whether a loan is approved or rejected.

## 📊 Data Analysis

The dataset is first inspected to understand its size, columns, data types, and overall structure.

Missing values and duplicate records are checked to maintain data quality.

The project also identifies unrealistic or invalid values that may affect the analysis.

---

## 🧹 Data Cleaning

Data cleaning is performed to improve the quality of the dataset.

The following issues are checked and handled:

* Missing values
* Duplicate rows
* Unrealistic ages
* Invalid credit scores
* Negative income
* Negative existing loans
* Other inconsistent values

After cleaning, the dataset is made ready for further analysis.

---

## 📈 Data Visualization

Different visualizations are created to understand the data.

The project includes:

* Approved vs Rejected applications
* Credit score distribution
* Income distribution
* Credit score vs approval
* Income vs approval
* Loan amount vs approval
* Correlation heatmap

These visualizations help identify patterns and relationships between financial factors and loan approval.

---

## ⚙️ Feature Engineering

A new feature called `debt_burden` is created to represent the relationship between the loan amount and applicant income.

Another useful feature is also created based on the available dataset information.

Feature engineering helps prepare the dataset for machine learning analysis.

---

## 🎯 Target Variable

The `approved` column is used as the target variable.

The dataset is separated into:

* **X:** Input features
* **y:** Target variable (`approved`)

This prepares the data for building a machine learning model.
